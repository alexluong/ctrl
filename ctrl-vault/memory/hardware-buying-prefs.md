Alex doesn't weigh warranty much when buying hardware (dislikes dealing with warranty claims), so used / FB-group deals are on the table. Not handy with hardware and doesn't want to spend time on it: prefers buying a working box from one shop or seller over DIY or messaging many shops. Likes GearVN; dislikes Phong Vũ-type chains. Lives in HCMC (Ho Chi Minh City), Vietnam — prefer HCMC shops/sellers.

**How to apply:** don't discount used deals for lacking warranty; do still push pre-purchase checks that catch dead-on-arrival / locked units (BIOS lock, SSD health, boot test at pickup). See [[task-1-dev-box]] notes in ctrl-vault/work/task-1/research.md.
