# spike shipped

**Doing:** built and deployed the WS1 spike with Alex in the session, steering as it went.

**What changed under me, in order:**
1. D-3 landed (Go dropped, TS Workers).
2. I built a two-app scaffold (Node API + Vite SPA, Postgres, compose) optimising for "Cloudflare is deployment-only". Alex pushed back: why two apps, why not one server-rendered app with one SQL db (D1?).
3. He was right that D1 being SQLite makes the dev/prod split cheap — local SQLite file, D1 deployed, one schema.
4. He asked for TanStack Start. Scrapped the two-app scaffold, rebuilt.
5. Compose stays, for port control + worktrees + future services, not because the DB needs it.

**Found:**
- The official TanStack-on-Cloudflare path runs workerd in dev. Avoided it: Node + SQLite in dev, Workers plugin only on a `DEPLOY_TARGET=cloudflare` build, one aliased module as the whole Cloudflare surface. Verified the alias actually swaps by grepping the built bundle.
- Free universal cert is one label deep. `stg.solex.collie.studio` fails TLS; `solex-stg.collie.studio` works. Cost me a deploy to find out.
- `toLocaleString()` in SSR = hydration mismatch. Real bug, fixed, and it foreshadows a product question about hotel-local time.
- Verifying via curl against TanStack server functions is a dead end (seroval wire format). Playwright in the scratchpad was the right call and took 5 minutes.
- pnpm 11 moved `onlyBuiltDependencies` to pnpm-workspace.yaml as `allowBuilds`; the `.npmrc` form collie-ui uses is silently ignored now. Worth knowing next time I touch collie-ui.

**Judgement call to flag:** I committed once as a single fat commit, then undid it before pushing because Alex asked for clear history. Final history is 7 commits, each one thing. Should have planned the sequence before writing files.

**Blocked:** nothing.

**Next:** architect's call on storage shape (my take is in `stack.md`: D1 for log + projections, optimistic concurrency, no Durable Object, Hookdeck deferred). Then first real slice — probably Setup + Rooms, since the room board is the thing the client actually looks at.
