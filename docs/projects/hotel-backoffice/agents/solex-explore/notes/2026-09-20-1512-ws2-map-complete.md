**The findings that matter:**

2. **No rate plans** — every rate typed by hand. Client's "auto rate" wish = new capability.
3. **Channel is typed into the guest name** (AGD/CTRIP/TVLK/EXP). CM integration (Siteminder/Staah) exists but unused. Alex: manual today, improvement target.
4. **Excel export is broken** — data: URL truncates at first `#`, every export is title-only. No supported data-out path exists. Alex: fine, start fresh, migration later.
5. **Night audit off** → days never formally closed; "revenue today" is ad-hoc.
6. **Housekeeping module unused** (no staff/shifts assigned); restaurant barely used. Two real personas: manager (read) + receptionist (everything).
7. Everything is attributed (created/edited/checked-in by, per-booking log); discounts carry request→edit→approve trail.
8. Cancellations/no-shows are statuses, not deletions.
9. `?page=employee` leaks PHP errors: install path, raw SQL, a **broken ODBC link to an Access file** for staff clock-in. Evidence of scattered data + sloppy exposure; told Alex, not ours to fix.
