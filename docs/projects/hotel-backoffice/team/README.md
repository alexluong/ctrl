# team/ — shared notes

Any agent appends. Every entry dated + signed `— <agent>`. Architect prunes/promotes into `../README.md`.

| file | what |
|---|---|
| `decisions.md` | decision log. Proposed by anyone; **Accepted** only by architect (or Alex). |
| `questions.md` | open questions for Alex / the client. Append; whoever gets the answer fills it in. |
| `log.md` | cross-agent chronological: "done X", "found Y that affects Z", handoffs. Replaces status chatter over messages. |
